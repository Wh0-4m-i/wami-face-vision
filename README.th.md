## เซิร์ฟเวอร์ในเครื่องและการประมวลผล

ทุกอย่างทำงานในเครื่องของคุณ ไม่มีรูป วิดีโอ หรือข้อมูลใบหน้าถูกส่งออกไปที่ใด

| | |
|---|---|
| **เซิร์ฟเวอร์** | Flask, `http://localhost:5000` (พอร์ต 5000) |
| **การผูกเครือข่าย** | `0.0.0.0` — เครื่องอื่นในเครือข่ายเดียวกันเข้าถึงได้ |
| **การยืนยันตัวตน** | ไม่มี |
| **โมเดล** | InsightFace `buffalo_l` (ตรวจจับ + ArcFace) ดาวน์โหลดตอนรันครั้งแรก |
| **การประมวลผลโมเดล** | ONNX Runtime — ลอง CUDA (GPU NVIDIA) ก่อน ถ้าไม่มีใช้ CPU |
| **รูปแบบการทำงาน** | ทีละไฟล์ (ไม่ขนาน) |
| **RAM** | เก็บ embedding ไม่เกิน 20 ตัวอย่างต่อคน (~40 KB ต่อคน) |
| **ต้นทุนวิดีโอ** | ถอดรหัส ~10 เฟรมต่อคลิป ไม่ขึ้นกับความยาวคลิป |
| **ดิสก์** | ไฟล์ต้นฉบับถูก **คัดลอก** ต้องมีพื้นที่ว่างเพิ่มประมาณเท่าขนาดข้อมูลที่ประมวลผล |
| **สถานะ** | `.face_db/` (embedding, ดัชนีไฟล์ที่ประมวลผลแล้ว) และ `.thumbnails/` บันทึกทุก 10 ไฟล์ |
| **ความเร็ว** | ยังไม่ได้วัด benchmark ขึ้นกับ GPU/CPU และจำนวนไฟล์ ควรลองกับชุดย่อยก่อน |

> **ความปลอดภัย:** เซิร์ฟเวอร์ไม่มีระบบล็อกอินและฟังทุก interface ควรรันบนเครือข่ายที่ไว้ใจเท่านั้น
> **ความเป็นส่วนตัว:** `.face_db/` และ `.thumbnails/` เป็นข้อมูลชีวมิติ ห้ามเผยแพร่ (อยู่ใน `.gitignore` แล้ว)

## แนะนำโปรเจกต์

**ArcFace Dataset Sorter** จัดระเบียบคลังภาพ/วิดีโอตาม *คนที่ปรากฏในไฟล์*
ออกแบบสำหรับชุดข้อมูลขนาดเล็กถึงกลาง (ประมาณ **1–2 TB**) ที่ **คัดและ Clean เรียบร้อยแล้ว**
ใบหน้าค่อนข้างชัด และมีคนตรวจโฟลเดอร์ `Waiting/` ภายหลัง

เป็น pipeline และหน้าเว็บที่ต่อยอดจากโมเดลสำเร็จรูป ไม่ได้เทรนหรือแจกโมเดลของตัวเอง

![ขั้นตอนการประมวลผล](<ArcFace-Based Face Dataset Organizer — v1.0.0/docs/pipeline.svg>)

**วิธีทำงาน**

1. อ่านไฟล์จาก `Clean/` (เฉพาะระดับบนสุด **ไม่เข้าโฟลเดอร์ย่อย**) และข้ามไฟล์ที่ประมวลผลแล้ว
2. ตรวจจับใบหน้า สร้าง ArcFace embedding 512 มิติของแต่ละใบหน้า
3. เทียบกับฐานข้อมูลบุคคลด้วย cosine distance แล้วจัดไฟล์:
   - ใกล้พอ → `Sorted/Person_XXXX/`
   - กึ่งๆ → `Waiting/possibly_Person_XXXX/`
   - ไกลเกิน → สร้างบุคคลใหม่
   - ไม่พบใบหน้า → `Waiting/no_face_detected/`
4. วิดีโอ: สุ่มเฟรมจากช่วงต้นคลิป ใบหน้าซ้ำในคลิปเดียวกันนับเป็นคนเดียว
5. ไฟล์ต้นฉบับ **ถูกคัดลอก ไม่ย้ายและไม่ลบ**

**เหมาะกับ:** ชุดข้อมูลที่คัดแล้ว ใบหน้าชัด รันเป็นรอบ มีคนตรวจ `Waiting/`
**ไม่เหมาะกับ:** กล้องวงจรปิด ใบหน้าเล็ก/เบลอมาก งาน real-time หรือการยืนยันตัวตน

**รูปแบบไฟล์ที่รองรับ**
รูปภาพ: JPG, JPEG, PNG, BMP, WEBP, GIF · วิดีโอ: MP4, AVI, MOV, MKV, WMV, FLV, WEBM

## เริ่มต้นใช้งาน

**ความต้องการ:** Python 3 และแพ็กเกจใน `requirements.txt` (InsightFace, ONNX Runtime, OpenCV, NumPy, Flask ฯลฯ)
GPU NVIDIA ไม่บังคับ

### Windows
1. ดับเบิลคลิก `INSTALL.bat` (ติดตั้ง Python 3.11 ผ่าน winget หากยังไม่มี แล้วติดตั้งแพ็กเกจ)
2. ดับเบิลคลิก `START.bat`
3. เปิด http://localhost:5000

### Linux / macOS
```bash
pip install -r requirements.txt
python app.py
```
แล้วเปิด http://localhost:5000 ปุ่มเปิดโฟลเดอร์ในหน้าเว็บเรียก `explorer` ใช้ได้เฉพาะ Windows
ส่วนอื่นข้ามแพลตฟอร์มได้ (ยังไม่ได้ทดสอบบนระบบอื่น)

### วิธีใช้
1. วางรูป/วิดีโอที่คัดแล้วใน `Clean/` โดยตรง (ไม่ใส่โฟลเดอร์ย่อย)
2. กด **Start** แล้วดูความคืบหน้า
3. ตรวจผลลัพธ์:

```
Clean/    ← ข้อมูลนำเข้า
Sorted/   ← หนึ่งโฟลเดอร์ต่อหนึ่งคน (เปลี่ยนชื่อ/รวมคนได้จากหน้าเว็บ)
Waiting/  ← ไฟล์ที่ไม่มั่นใจ รอตรวจด้วยตนเอง
```

หยุดแล้วกด Start ใหม่จะทำต่อจากเดิม

## การตั้งค่าขั้นสูง

ปรับในแท็บ **Settings** หรือ `POST /api/settings` มีผลตั้งแต่ไฟล์ถัดไป

![เกณฑ์ระยะห่าง](<ArcFace-Based Face Dataset Organizer — v1.0.0/docs/thresholds.svg>)

| ค่า | Default | คำอธิบาย |
|---|---|---|
| Similarity Threshold | 0.40 | ระยะ cosine สูงสุดที่ถือว่าเป็นคนเดียวกัน ต่ำ = เข้มงวด (แนะนำ 0.35–0.45) |
| Waiting Threshold | 0.48 | เกินค่านี้ถือเป็นคนใหม่ ระหว่างสองค่าไฟล์ไป Waiting |
| Min Face Confidence | 0.70 | ความมั่นใจขั้นต่ำของการตรวจจับใบหน้า |
| Video Scan Length | 20 วินาที | สแกนเฉพาะช่วงต้นคลิป (แนะนำ 10–20) |
| Video Frame Interval | 2.0 วินาที | สุ่มหนึ่งเฟรมทุก N วินาที ≈10 เฟรมต่อคลิป (แนะนำ 1–3) |

ค่าคงที่ใน `face_recognizer.py`: `MIN_FACE_SIZE` (50 px), `SAVE_EVERY_N_FILES` (10)
เปลี่ยน threshold แล้วต้องการสแกนใหม่ทั้งหมด ให้เรียก `POST /api/reset-processed`

**HTTP API**

| Endpoint | หน้าที่ |
|---|---|
| `POST /api/start`, `POST /api/stop` | เริ่ม / หยุดประมวลผล |
| `GET /api/status` | ความคืบหน้า สถิติ และ log |
| `GET /api/persons` | รายชื่อบุคคล |
| `POST /api/persons/<id>/rename` | เปลี่ยนชื่อบุคคล |
| `POST /api/persons/merge` | รวมบุคคลสองคน |
| `GET /api/thumbnail/<id>` | รูปย่อใบหน้า |
| `GET /api/folders` | รายการโฟลเดอร์ |
| `GET` / `POST /api/settings` | อ่าน / เปลี่ยนการตั้งค่า |
| `POST /api/reset-processed` | ล้างรายการไฟล์ที่ประมวลผลแล้ว |
| `GET /api/stats/summary` | ตัวเลขสรุป |

Log ถูกเขียนลง `face_recognition.log` และแสดงที่ console
